# Keylogger Finder Windows Release

Standalone Windows executable. No Python installation required.

## How to use

1. Download KeyloggerFinder.exe
2. Open it to run. A splash screen appears while the app loads
3. Choose Quick scan or Full scan and click Scan now
4. Optionally save the report with Save report

## Requirements

* Windows 10, 11 or Server 2016 and above, 64 bit
* No dependencies. Everything is bundled inside the EXE

## Build info

Built with PyInstaller on Windows Server 2022, targeting 64 bit Windows.
